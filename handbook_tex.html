1. Text Formatting (With Previews)

1.1. Text Style and Color

To use colors, you must first add \usepackage{xcolor} to your preamble.

This is \textbf{bold text}.\nThis is \textit{italic text}.\nThis is \textcolor{red}{red text}.\nWe can also have \textcolor{blue}{nested styles}, like \textbf{\textcolor{blue}{bold blue text}}.

2. Creating Boxes and Containers

Boxes are great for highlighting information or structuring content.

2.1. Simple Boxes with \fbox

The \fbox command puts a simple frame around any content.

\fbox{This is a simple framed box.}

Output Preview:

This is a simple framed box.

2.2. Advanced Boxes with tcolorbox

For full control over colors, spacing, and titles, the tcolorbox package is essential. Add \usepackage{tcolorbox} to your preamble.

% A basic colored box
\begin{tcolorbox}
    This is a tcolorbox. It has a light grey background and a thin border by default.
\end{tcolorbox}

% A box with a title and custom colors
\begin{tcolorbox}[
    colback=blue!5!white,  % Background color: 5% blue
    colframe=blue!75!black, % Frame color: 75% blue
    title=My Titled Box]
    This box has a title and custom colors for the background and frame.
\end{tcolorbox}

Output Preview:

This is a tcolorbox. It has a light grey background and a thin border by default.
My Titled Box
This box has a title and custom colors for the background and frame.

3. Mathematical Equations

Best Practice: Avoid $$...$$

Always use \[ ... \] or the equation environment instead of $$...$$ to avoid potential spacing problems.

\begin{equation}
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\label{eq:quadratic}
\end{equation}

Output Preview:

x = −b ± √(b² − 4ac) / 2a

4. Page Numbering and Headers

By default, LaTeX numbers your pages. To customize this, the fancyhdr package is the standard choice. Add \usepackage{fancyhdr} to your preamble.

% Apply this in your preamble
\pagestyle{fancy}
\fancyhf{} % Clear all header and footer fields
\rhead{Linear Algebra Exam}
\lhead{Your Name}
\cfoot{\thepage} % Puts the page number in the center of the footer

5. Drawing with TikZ

TikZ allows you to create vector graphics directly with code.

\begin{tikzpicture}
    \draw[blue, thick] (0,0) circle (1.5cm);
    \fill[red] (0,0) rectangle (1,1);
    \node at (0, -2) {A circle and a square};
\end{tikzpicture}

6. Practical Templates

These templates incorporate the concepts discussed above.

University Exam Template

\documentclass{article}
\usepackage{amsmath, amsthm}
\usepackage{geometry}
\usepackage[svgnames]{xcolor}
\usepackage[most]{tcolorbox}
\usepackage{fancyhdr}

\geometry{a4paper, margin=1in}

% Header and Footer Setup
\pagestyle{fancy}
\fancyhf{} 
\lhead{MATH 201: Linear Algebra}
\rhead{Final Exam}
\cfoot{Page \thepage}

% Define a custom problem box
\newtcolorbox{problembox}[2][]{
    title=#2, 
    colback=WhiteSmoke, 
    colframe=DarkSlateGray, 
    fonttitle=\bfseries, 
    #1
}

\begin{document}

\begin{problembox}{Problem 1: Matrix Operations (20 Points)}
    Given the matrices...
\end{problembox}

\begin{problembox}{Problem 2: Proof (25 Points)}
    Prove that for any invertible matrix $A$, the inverse $A^{-1}$ is unique.
\end{problembox}

\end{document}
